01 · พื้นฐาน

AI คืออะไร?

AI (Artificial Intelligence) คือเทคโนโลยีที่ทำให้คอมพิวเตอร์ทำงานบางอย่าง
ที่ต้องอาศัยความสามารถของมนุษย์ได้

มนุษย์
  • คิด Thinking
  • เรียนรู้ Learning
  • วิเคราะห์ Analyzing
เลียนแบบบางส่วน
AI
  • จดจำรูปแบบ Recognizing
  • คาดการณ์ Predicting
  • สร้างเนื้อหา Generating
แนะนำวิดีโอแปลภาษาวิเคราะห์ภาพช่วยเขียนรายงาน

AI เรียนรู้จาก “รูปแบบในข้อมูล” — ไม่ได้คิดหรือเข้าใจเหมือนมนุษย์ในทุกด้าน

[1:30–2:30] นิยามง่าย ๆ: AI คือเทคโนโลยีที่ทำให้คอมพิวเตอร์ทำงานบางอย่างที่ปกติต้องใช้ความสามารถของคน

(กด) มนุษย์คิด เรียนรู้ วิเคราะห์จากความเข้าใจ — AI เลียนแบบได้บางส่วน: จดจำรูปแบบ คาดการณ์ และสร้างเนื้อหา

(กด) ตัวอย่างที่เราใช้ทุกวัน: YouTube แนะนำวิดีโอ, แปลภาษา, อ่านภาพเอกซเรย์, ช่วยร่างรายงาน

(กด) แต่ AI ทำงานจาก รูปแบบในข้อมูล ไม่ได้ “เข้าใจ” เหมือนเราทุกเรื่อง จึงตอบผิดได้อย่างมั่นใจ

คำถามกระตุ้น: “เช้านี้ ก่อนมาห้องประชุม ทุกคนใช้ AI ไปแล้วกี่ครั้ง โดยไม่รู้ตัว?”

เชื่อมต่อ: “AI ไม่ได้เพิ่งเกิด — มันเติบโตมากว่า 60 ปี มาดูเส้นทางกัน”

  • 2025–26ฟีเจอร์ Agent ในแอปหลัก

ยุคต่าง ๆ ทับซ้อนกัน — ปีที่แสดงคือ “เหตุการณ์สำคัญ” ไม่ใช่วันเริ่มยุค · แหล่งอ้างอิงกด R

[2:30–4:30] (แต่ละครั้งที่กด ยุคถัดไปจะสว่างขึ้น และเป็นยุคเดียวที่เด่นบนจอ)

Rule-based: ปี 1966 มี ELIZA โปรแกรมคุยได้ แต่แค่จับคำแล้วตอบตามกฎ ยุค 1970 มี MYCIN ระบบผู้เชี่ยวชาญด้านยาฆ่าเชื้อ — AI ทางการแพทย์มีมาตั้งแต่ตอนนั้น

Machine Learning: แทนที่คนเขียนกฎ ให้เครื่องเรียนจากตัวอย่าง คำนี้เกิดตั้งแต่ปี 1959 และเห็นชัดในระบบแนะนำหนังอย่าง Netflix

Deep Learning: ปี 2012 AlexNet ทำให้การจำแนกภาพแม่นขึ้นมาก — รากฐานของ AI อ่านภาพทางการแพทย์ ปี 2016 AlphaGo ชนะแชมป์โลกโกะ

Generative AI: ปี 2017 เกิด Transformer สถาปัตยกรรมเบื้องหลัง LLM แทบทุกตัว และปลายปี 2022 ChatGPT ทำให้คนทั่วไปเข้าถึง

Agentic AI: ตั้งแต่ปี 2024 AI เริ่มใช้คอมพิวเตอร์และเครื่องมือได้เอง และปี 2025–26 ฟีเจอร์ Agent เข้ามาในแอปหลักทั้งสามค่าย

คำถามกระตุ้น: “คิดว่าจาก ChatGPT ถึง Agent ใช้เวลากี่ปี?” (คำตอบ: ไม่ถึง 3 ปี)

เชื่อมต่อ: “ให้เห็นภาพง่ายขึ้น ลองเปรียบ AI เป็นคนที่กำลังโต”

04 · ประเภทของ AI

AI ไม่ได้มีแค่ Chatbot

AI

แตะแต่ละกิ่ง หรือกด “ถัดไป” เพื่อดูตัวอย่าง

Predictive AI

ใช้ข้อมูลในอดีตคาดการณ์สิ่งที่จะเกิด — เช่น คาดการณ์จำนวนผู้ป่วยนอกช่วงเทศกาล

Generative AI

สร้างเนื้อหาใหม่ — เช่น ร่างหนังสือเวียน หรือโปสเตอร์ประชาสัมพันธ์

Multimodal AI

อ่านได้หลายรูปแบบพร้อมกัน — เช่น อ่านเอกสารสแกน + รูป + ข้อความ

Agentic AI

ลงมือทำหลายขั้นตอนเอง — เช่น ค้นข้อมูล → สรุป → ทำตาราง

* แบ่งตามลักษณะการใช้งาน แต่ละประเภทอาจทับซ้อนกันได้

[6:00–7:00] ตรงกลางคือ AI กิ่งทั้งสี่คือการแบ่งตามการใช้งาน (กดทีละกิ่ง)

Predictive คาดการณ์ เช่น จำนวนผู้ป่วยช่วงสงกรานต์ · Generative สร้างข้อความ ภาพ เสียง โค้ด · Multimodal รับหลายรูปแบบพร้อมกัน · Agentic วางแผนและลงมือหลายขั้น

ตัวเดียวเป็นได้หลายแบบพร้อมกัน — แบ่งเพื่อให้เข้าใจง่ายเท่านั้น

คำถามกระตุ้น: “ในหน่วยงานของคุณ มีงานไหนที่เป็น ‘การคาดการณ์’ บ้าง?”

เชื่อมต่อ: “ทีนี้ ตอนพูดว่า ‘ใช้ ChatGPT’ เราใช้อะไรอยู่กันแน่?”

05 · แอป กับ โมเดล

ChatGPT ไม่ใช่ชื่อโมเดลทั้งหมด

AI — วงใหญ่สุด ระบบที่ทำงานแบบ “ฉลาด” ทั้งหมด

Generative AI — กลุ่มที่สร้างเนื้อหาใหม่ได้

LLM — Large Language Model เข้าใจและสร้างภาษา

โมเดล= เครื่องยนต์
≠
แอป= ตัวรถ

แอปที่เราใช้ กับโมเดลที่อยู่เบื้องหลัง ไม่ใช่สิ่งเดียวกัน

[7:00–8:00] (กดทีละวง) AI วงใหญ่สุด → Generative AI อยู่ข้างใน → LLM — Large Language Model โมเดลภาษาขนาดใหญ่ อยู่ในนั้นอีกที

(กด) เปรียบง่าย ๆ: โมเดล = เครื่องยนต์ และ แอป = ตัวรถ — แอปเดียวกันเปลี่ยนเครื่องยนต์ข้างในได้ ChatGPT จึงเป็นชื่อแอป ไม่ใช่ชื่อโมเดลทั้งหมด

คำถามกระตุ้น: “แอปที่คุณใช้อยู่ ตอนนี้ใช้โมเดลรุ่นไหน — เคยลองเปิดดูไหม?”

เชื่อมต่อ: “มาดูสามค่ายหลักกัน”

11 · Token Simulator

งานเยอะแค่ไหน ใช้ Token เท่าไร?

Token = หน่วยย่อยของข้อความที่โมเดลนับ ทั้งขาเข้า (Input) และขาออก (Output)

Token รวม380,000
Input300,000Output80,000
ค่าใช้จ่ายโดยประมาณ — กรอกราคาจากหน้าราคาทางการของรุ่นที่ใช้
กรอกราคาของโมเดลที่ใช้จริง เพื่อคำนวณค่าใช้จ่าย

ไม่มีราคาสมมติในหน้านี้ — ค่าใช้จ่ายจริงขึ้นกับรุ่นโมเดล ราคา ณ วันที่ใช้ และเครื่องมือเสริม · ภาษาไทยมักใช้ Token มากกว่าภาษาอังกฤษในข้อความยาวเท่ากัน

[15:00–16:30] AI ผ่าน API และ Agent คิดเงินตาม Token — หน่วยย่อยของข้อความ ทั้งที่เราส่งเข้าและที่มันตอบออก

ลองเลื่อนสด: งานสรุปแบบประเมิน 100 ชิ้น ชิ้นละ 3,000 token ขาเข้า ตอบ 800 → รวม 380,000 token · ลองเพิ่มเป็น 1,000 งานให้ผู้ฟังเห็นว่าโตเป็นสิบเท่า

(กด) เราไม่ใส่ราคาเอง เพราะแต่ละรุ่นราคาไม่เท่ากันและเปลี่ยนได้ ถ้าจะประมาณ ให้กรอกราคาจริงจากหน้าราคาทางการของรุ่นที่ใช้ — โดยทั่วไป Output แพงกว่า Input และเครื่องมือเสริมคิดเงินเพิ่ม

คำถามกระตุ้น: “ถ้า Agent วนแก้งานซ้ำ 10 รอบ Token จะเพิ่มเป็นเท่าไร?” (ประมาณ 10 เท่า — จึงต้องมี Budget Limit)

เชื่อมต่อ: “แล้วต่อจากนี้ AI จะไปทางไหน?”

13 · ความปลอดภัย

ก่อนให้ AI ทำงานแทน ต้องมี 4 อย่างนี้

ข้อมูลผู้ป่วยต้องปลอดภัย

อย่าใส่ข้อมูลที่ระบุตัวตนได้ในระบบที่ไม่ได้รับอนุญาต — ลบชื่อ HN เลขบัตรก่อนเสมอ

มนุษย์ต้องตรวจสอบ

AI อาจตอบผิดหรือสร้างแหล่งอ้างอิงที่ไม่มีจริง — ข้อมูลการแพทย์ต้องผ่านผู้เชี่ยวชาญ

จำกัดสิทธิ์ของ Agent

ให้สิทธิ์เท่าที่จำเป็น เริ่มจากอ่านอย่างเดียว — การส่ง แก้ หรือลบ ต้องให้คนอนุมัติ

ตั้งเพดานค่าใช้จ่าย

กำหนดเพดาน Token / ค่าใช้จ่ายต่อวัน — แจ้งเตือนและหยุดอัตโนมัติเมื่อถึงเพดาน

ทุกงานของ AI ต้องมี “เจ้าของงาน” ที่เป็นมนุษย์

[17:30–19:00] สี่เรื่องที่ต้องมีก่อนให้ AI ทำงานแทน (กดทีละข้อ)

1) ข้อมูลผู้ป่วย — ห้ามใส่ชื่อ HN เลขบัตร ในระบบที่โรงพยาบาลไม่ได้อนุญาต · 2) คนตรวจสอบ — AI อาจแต่งแหล่งอ้างอิงขึ้นมา ข้อมูลการแพทย์ต้องให้ผู้เชี่ยวชาญตรวจ

3) สิทธิ์ของ Agent — เหมือนพนักงานใหม่ ให้อ่านอย่างเดียวก่อน การส่ง แก้ ลบ ต้องมีคนกดอนุมัติ · 4) เพดานค่าใช้จ่าย — จากตัวคำนวณเมื่อกี้ งานวนซ้ำทำให้ Token พุ่งได้ จึงต้องตั้งเพดานและให้หยุดเองเมื่อถึง

คำถามกระตุ้น: “ถ้า Agent ส่งอีเมลผิดคนในนามหน่วยงาน — ใครรับผิดชอบ?” (คำตอบ: คนที่เป็นเจ้าของงาน)

เชื่อมต่อ: “สรุปทั้งหมดในประโยคเดียว”
